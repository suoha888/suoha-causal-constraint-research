# Capital bridge

The capital bridge turns an operating observation into shareholder economics:

    driver -> volume / price / mix / yield / utilization
    -> revenue -> gross profit -> operating cash flow
    -> capex -> financing -> share count -> per-share value

For every arrow, record:

- the variable and unit;
- baseline and scenario;
- timing;
- evidence or assumption;
- sensitivity;
- whether the link is measured, inferred, or hypothetical.

Do not use revenue growth as a proxy for per-share value when capex, working capital, debt, options, convertibles, or equity issuance can change the result.

## Market state

At minimum record price, shares outstanding, market value, currency, timestamp, source, and arithmetic method. If a source reports diluted shares and another reports basic shares, preserve both and state which one is used.
