# Source and data policy

The public package ships methods and synthetic fixtures, not a research archive.

## Public

Schemas, validators, synthetic examples, generic adapter contracts, and links to standards or official public records may be published.

## Restricted

Source metadata may be retained in an access-controlled workspace when redistribution is not permitted. Public output may expose only a stable evidence ID, source type, hash, date fields, and an uncertainty label.

## Private

Personal notes, private conversations, purchased databases, non-public documents, credentials, and raw historical collections stay outside the repository. The private overlay is not a substitute for permission to use a source.

## Synthetic

Synthetic examples must use fictional entities, clearly marked values, and no copied source language. Synthetic fixtures are for validator behavior, not investment conclusions.

## Hygiene

Before every release, scan file contents, paths, links, fixtures, generated output, Git metadata, and package archives. The scanner reports a digest and location, not the forbidden token itself.
